# Excel 业绩分析套用 PPT 模板

## 用户故事

业务同事需要把区域与渠道业绩表做成管理层汇报，公司要求沿用统一 PPT 模板。分析可以更新，但背景、配色、标题层级和卡片位置需要保持一致。

本案例复现该工作流，并用更小的虚构数据集替换实际业务数据。仅保留供理解的维度与汇报形式，不是原始业务数据的按比例变换。

## 演示输入

单位：万元。时间范围：演示年度上半年。

| 区域 | 渠道 | 收入预算 | 实际收入 |
| --- | --- | ---: | ---: |
| 区域 A | 线下 | 1,400 | 1,640 |
| 区域 A | 线上 | 800 | 760 |
| 区域 B | 线下 | 1,600 | 1,800 |
| 区域 B | 线上 | 1,200 | 1,000 |
| 合计 | | 5,000 | 5,200 |

## 可追溯的结论

- 整体达成率：5,200 ÷ 5,000 = 104.0%，超额 200 万元。
- 区域 B 收入：1,800 + 1,000 = 2,800 万元，高于区域 A 的 2,400 万元。
- 线下收入：1,640 + 1,800 = 3,440 万元，较预算 3,000 万元超额 440 万元，达成率约 114.7%。
- 线上收入：760 + 1,000 = 1,760 万元，较预算 2,000 万元少 240 万元，达成率 88.0%。

这些数据只能支持差异描述，不能证明缺口由转化率、库存或投放造成。原因分析需要额外证据。

## 套版映射

概览页的标题与摘要对应整体结论，原有四张红金卡片依次容纳收入、达成率、区域贡献和渠道缺口。渠道页沿用原模板的四个线框图标卡片，映射为线下收入、线上收入、线下增量、线上缺口。

宣传主图由图像生成工具合成，可能存在缩放与细节重绘。`images/template-overview.png`、`images/report-overview.png`、`images/report-channels.png` 是直接渲染的对比图，可独立查看。它们不是原生 PowerPoint 验收证据，也不用于计算所谓“90% 相似度”。
